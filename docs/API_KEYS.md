# API-ключи: подключение Claude Code, Codex и интеграций

Персональный API-ключ позволяет агенту или скрипту работать с роадмапом от имени конкретного сотрудника. Пароль агенту не передаётся.

## Как получить ключ

1. Войдите в роадмап → **Профиль** → **API-ключи** → **Новый ключ**.
2. Назовите ключ (например, «Claude Code на ноутбуке»), выберите разрешения и срок действия (до 1 года).
3. Скопируйте ключ: он показывается **один раз**. В базе хранится только SHA-256 хэш.
4. Положите ключ в переменную окружения, а не в код, чат или репозиторий:

   ```bash
   export RAFINAD_API_KEY='rr_xxxxxxxx_…'
   export RAFINAD_URL='https://products-roadmap.ezhirov-es.workers.dev'
   ```

Ключ отзывается в профиле. Администратор может принудительно отозвать любой ключ: **Администрирование → API-ключи**. Отзыв, истечение срока и отключение пользователя действуют сразу.

## Права

Эффективные права = **роль владельца ∩ разрешения ключа**. Роль и членство в отделах перечитываются на каждом запросе.

| Разрешение | Что даёт |
| --- | --- |
| `tasks:read` | `GET` задач, обзора, приоритетов, релизов, эпиков, офферов, календаря, спринтов, роадмапа |
| `tasks:create` | `POST /api/features` (только если роль product/admin) |
| `tasks:update` | `PATCH /api/features/:id`, расписание, связи, комментарии, оценки, блокеры |
| `priorities:write-own` | оценка задачи за **свои** отделы (`PUT /api/features/:id/votes/:departmentId`) |
| `exports:read` | выгрузка задач (появится в P08) |

Что ключ не может делать ни при каких разрешениях:
- управлять ключами;
- вызывать админку, импорт, планирование, авторизацию;
- менять оценку чужого отдела (даже ключ администратора).

Лимит — 120 запросов в минуту на ключ, сверх него ответ 429. Каждое изменение пишется в журнал с `api_key_id`; сам ключ в журнал не попадает.

Скрытые задачи продукта видны только ключам пользователей с ролью product/admin.

## Примеры

```bash
# кто я и какие у ключа разрешения
curl -s "$RAFINAD_URL/api/auth/me" -H "Authorization: Bearer $RAFINAD_API_KEY"

# найти задачи
curl -s "$RAFINAD_URL/api/features?q=выплаты&hide_closed=1" -H "Authorization: Bearer $RAFINAD_API_KEY"

# прочитать карточку
curl -s "$RAFINAD_URL/api/features/RF-12" -H "Authorization: Bearer $RAFINAD_API_KEY"

# создать задачу; инициатор указывается явно — владелец ключа становится автором, а не инициатором
curl -s -X POST "$RAFINAD_URL/api/features" \
  -H "Authorization: Bearer $RAFINAD_API_KEY" -H "Content-Type: application/json" \
  -d '{"title":"Экспорт выплат в 1С","description":"…","task_kind":"planned",
       "initiator":{"type":"department","department_id":"dep_finance"}}'

# изменить задачу (version — из карточки, защита от одновременной правки)
curl -s -X PATCH "$RAFINAD_URL/api/features/RF-12" \
  -H "Authorization: Bearer $RAFINAD_API_KEY" -H "Content-Type: application/json" \
  -d '{"assignee_name":"Иванов Иван","version":7}'
```

### Подсказка для Claude Code / Codex

> Роадмап Rafinad доступен по `$RAFINAD_URL`, ключ лежит в `$RAFINAD_API_KEY` (заголовок `Authorization: Bearer`). Перед изменением прочитай карточку и передай её `version`. Инициатора задачи указывай явно. Ключ не выводи в лог и в ответ.

## Ошибки

| Код | Причина |
| --- | --- |
| 401 `invalid_api_key` | ключ неверный, отозван, просрочен или пользователь отключён |
| 403 | нет нужного разрешения у ключа, не позволяет роль или действие недоступно по ключу |
| 404 | задачи нет или она скрыта от владельца ключа |
| 409 `version_conflict` | карточку изменили — перечитайте и повторите |
| 429 `rate_limited` | больше 120 запросов в минуту |
