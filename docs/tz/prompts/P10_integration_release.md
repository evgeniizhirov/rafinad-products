# Готовое задание Codex: P10 — интеграция и релизный аудит

**Скопируй текст задания после слияния всех предыдущих модулей. Приложи `00_MASTER_TZ.md` и ссылки на закрытые PR P01–P09.**

Репозиторий: `evgeniizhirov/rafinad-products`. Работай в ветке `codex/10-integration-audit` от актуального `main`. **Нельзя самостоятельно применять миграции к удалённой D1 или деплоить в Production.**

1. Пройди 20 сквозных сценариев T01–T20 из `00_MASTER_TZ.md` — там есть даты спринтов, ACL, типы задач, экспорт/импорт, аналитика. Добавь тесты на интеграцию, если сценарии покрыты неполно.
2. Проверь исторические данные и аддитивность миграций D1 (чистая БД и локальная копия схемы/данных, воспроизводимые сиды). Ни одна прежняя задача, голос отдела, релизное включение или импортная привязка не должна исчезать.
3. Проверь архитектурные инварианты: `visibility='internal'` не равен Product-private; баги не участвуют в расчёте плановых часов; месяцы не равны спринтам; смена ставок не меняет закрытые периоды; endpoint с API-ключом не обходит RBAC; Google Write не затрагивает листы кроме `Import`.
4. Пройди трассировку прав: guest/department_lead/product/admin + ключи с разными scope; скрытые задачи не раскрываются через overview, граф, релизы, экспорт, Google-таблицу, аналитику и ошибки.
5. Запусти настоящие `npm run typecheck`, `npm test`, `npm run build`; локальный dev smoke test UI и API. Проверь стабильность при повторном импорте и повторной генерации периодов.
6. Создай `docs/RELEASE_NOTES.md` и `docs/PRODUCTION_ROLLOUT.md` с упорядоченными миграциями D1, ручными шагами Cloudflare (runtime secrets и Google Editor только для export target), smoke checks, бэкапом/планом восстановления, критериями rollback.
7. Верни финальный чеклист из «готово / заблокировано / не проверялось» с точными командами и PR. Никаких фиктивных успехов и никакой автоматической публикации.

**Ожидаемый результат:** отдельный PR на тесты, интеграционные исправления и rollout-документацию; только после одобрения владелец может вручную применить D1 migrations и опубликовать Worker.
