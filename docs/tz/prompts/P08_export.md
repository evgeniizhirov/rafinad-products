## Конкретная работа

1. Работай после merge P02 и P03; после P05 желательно учитывать все типы. Изучи `worker/routes/features.ts`, `worker/lib/world.ts`, клиентские фильтры списка, `worker/lib/google.ts`, настройки импорт-источников. Реализуй отдельный export service, не раздувай existing imports code.
2. Кнопка «Экспорт» в общем списке: те же фильтры, все страницы результатов, выбор Excel `.xlsx` или Google Sheets. Одна строка одна задача, стабильный ID, тип, инициатор, статус/semantic, описание, даты, sprint/release, ответственный, автор и другие разрешённые поля. **Те же колонки** в обоих каналах.
3. Сервер выполняет фильтрацию и построчную/полевую ACL заново, без доверия клиентскому списку. Скрытые Product-задачи нельзя прочитать ни через export parameters, ни через role query. Лимиты и потоковая/постраничная обработка для больших выборок; защитить Excel от formula injection (значения, начинающиеся с =,+,-,@ должны быть текстовыми, где нужно).
4. Google экспорт — в разрешённый администратором документ, вкладка `Import`, ручной запуск; только эту вкладку заменять. Перед записью обязательное подтверждение: содержимое увидят все пользователи Google-документа. Не публиковать персональную скрытую задачу в общую таблицу без явного подтверждения уполномоченного пользователя. Audit export.
5. Текущий `worker/lib/google.ts` read-only; добавь write auth/scope на отдельном клиенте или аккуратно расширь. Для записи сервисный аккаунт должен иметь роль редактора целевой Google-таблицы. JSON оставлять исключительно в runtime Cloudflare Worker secrets. Не трогать существующий импорт/чтение. При ошибке — без частичного изменения соседних вкладок.
6. Не реализовывать cron/полноценный bidirectional sync/публикацию всех задач по расписанию.

## Критерии приёмки

- Идентичная выборка и колонки в XLSX и Google.
- Фильтры работают server-side и не ограничены текущей страницей.
- Чужие Product internal никогда не экспортируются.
- Google: только `Import`, соседние вкладки неизменны.
- Полный аудит и предупреждение о внешней видимости.
